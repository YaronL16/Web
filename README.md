# Yaron Lavi — Portfolio & Engineering Showcase

Modern portfolio website for **Yaron Lavi** (DevOps & Platform Engineer | B.Sc. Computer Science Student).

## Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (Carbon & Slate theme with Cyan & Emerald accents)
- **Icons:** Lucide React
- **CI/CD & Hosting:** GitHub Actions & GitHub Pages

## Architecture & Features
- **Interactive Platform Shell:** In-browser terminal simulation responding to `whoami`, `skills`, `projects`, `status`, `help`, and `clear`.
- **Selected Projects:** Production architectures including Echo (OpenShift DR orchestrator with kro & Kanister), Multi-Cluster GitOps (ArgoCD & Kyverno), AmanDate (FastAPI + React), and Voyager (Cloud-native telemetry).
- **Zero Local Footprint:** Pure remote build, bundling, and deployment executed strictly inside GitHub Actions runners.
